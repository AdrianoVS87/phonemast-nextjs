# Phone Mast Advice

WordPress site rebuilt on **Next.js 15** — MDX content, Sanity CMS, and the
original WordPress export migrated into the repo.

**Live:** [phonemast-nextjs.vercel.app](https://phonemast-nextjs.vercel.app)
**Stack:** Next.js 15 · TypeScript · Sanity · MDX · pnpm · Vercel

## Develop

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Deploys to Vercel on push to `main`.
